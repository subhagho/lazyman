# LazyMan
Attempts to solve the traveling salesman problem

## Python project setup

Create a virtual environment and install the package in editable mode:

```bash
python -m venv .venv
. .venv/bin/activate
python -m pip install -e .[dev]
```

Run the package:

```bash
python -m lazyman
```

Or use the installed console script:

```bash
lazyman
```

Run tests:

```bash
pytest
```
